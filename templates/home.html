Challenge Information

NASA missions like Kepler and TESS have discovered many exoplanets, but sifting through the vast datasets is time-consuming, hindering rapid identification and classification. We are developing a machine learning model using publicly available data to automate and accelerate the discovery and classification of exoplanets, making this process more efficient and accessible to everyone.

Our Model

Machine learning (ML) is a subfield of artificial intelligence (AI) focused on enabling systems to learn from data and improve performance on specific tasks without explicit programming. Our current ML system utilizes a Gradient Boosting Classifier, which enhances accuracy by sequentially combining predictions from multiple weaker decision trees. Our model, developed using this system and trained on NASA data, has achieved an accuracy of 97%.
